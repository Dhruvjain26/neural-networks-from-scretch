# Neural Networks from Scratch

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/Dhruvjain26/neural-networks-from-scratch/blob/main/autograd-engine.ipynb)


A hands-on learning project exploring the fundamentals of automatic differentiation, backpropagation, and neural networks using Python.

## About

This repository documents my journey into deep learning by implementing and experimenting with the core ideas behind a tiny neural network engine.

The goal is to understand what happens behind the scenes when a neural network performs a forward pass, calculates a loss, computes gradients, and updates its parameters during training.

Rather than treating neural networks as a black box, I'm exploring how their underlying mathematics and code work together.

## Topics Covered

- Scalar-valued computation and computational graphs
- Automatic differentiation
- Derivatives and gradients
- Backpropagation
- Building a simple neuron and multilayer perceptron
- Loss functions and gradient descent
- Training a neural network on a small dataset

## Tech Stack

- **Language:** Python
- **Environment:** Google Colab
- **Concepts:** Calculus, computational graphs, automatic differentiation, and deep learning fundamentals
